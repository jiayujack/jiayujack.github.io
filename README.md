# Jiayu Qin — Academic Homepage v2

A responsive, dependency-free academic homepage designed for GitHub Pages.

## Deploy to `jiayujack.github.io`

1. Back up the current repository.
2. Replace the repository root with the contents of this folder.
3. Commit and push to the default branch:

```bash
git add -A
git commit -m "Redesign academic homepage"
git push
```

GitHub Pages should update within a few minutes. No build command is required.

## Update content

- Main copy and links: `index.html`
- Design and responsive behavior: `assets/css/styles.css`
- Theme, navigation, and reveal motion: `assets/js/main.js`
- CV: replace `assets/docs/Jiayu_Qin_CV.pdf` using the same filename
- Portrait and research images: `assets/img/`
